# Alert Card OD Line Integration - Implementation Summary

## Overview

This document summarizes the changes made to integrate OD Line visualization for security alerts in the AlertCardManager component. OD Lines replace the previous `focusActors` approach, which couldn't handle items across different tile layers.

## Files Modified

### 1. AlertCardManager.tsx

**Major Changes:**

- Added OD Line API imports from `useDigitalTwinApi`
- Added color constants for OD Lines (red for active, green for merged)
- Made security handlers async to support OD Line operations
- Replaced focus/highlight logic with OD Line creation/deletion
- Added helper function `getAllCurrentLineIds()` to track line IDs

## OD Line Logic Flows

### Initial State (Security Alert Opens)

```
1. Create main→main self-referencing OD line
2. Line ID: "od_0" (generated by addODLines)
3. Color: Red
4. Focus on this line
```

### Select Affected Item (Toggle ON)

```
1. Add item to selectedSecurityItems state
2. Create single OD line for this item:
   - Upstream: [itemCoords, mainCoords] with ID "od_upstream_0"
   - Downstream: [mainCoords, itemCoords] with ID "od_downstream_0"
3. Color: Red
4. Open secondary card
5. Focus on ALL line IDs (selected + merged)
```

### Deselect Affected Item (Toggle OFF)

```
1. Remove item from selectedSecurityItems state
2. Delete OD line with ID "od_${type}_${index}"
3. Close secondary card
4. If remaining lines exist:
     Focus on remaining line IDs
   Else:
     Create main→main line and focus on it
```

### Merge Item (Click "Yes")

```
1. Add to mergedItems state
2. Change OD line color to green for ID "od_${type}_${index}"
3. Remove from selectedSecurityItems state
4. Close secondary card
5. Line remains visible in green (no refocus needed)
```

### Dismiss Item (Click "No")

```
1. Add to dismissedItems state
2. Remove from selectedSecurityItems state
3. Delete OD line with ID "od_${type}_${index}"
4. Close secondary card
5. If remaining lines exist:
     Focus on remaining line IDs
   Else:
     Create main→main line and focus on it
```

### Close Alert Card / Submit to Incident Management

```
1. Clear ALL OD lines (clearODLines)
2. Reset all state
3. Restore camera to original position
```

## OD Line ID Format

**Stable ID Format:** `od_${type}_${index}`

### Examples

- `od_upstream_0` - First upstream item
- `od_downstream_1` - Second downstream item
- `od_main_0` - Main→main self-referencing line

### Benefits

- Unique per item
- Easy to construct/reconstruct
- Type-safe tracking
- No conflicts between upstream/downstream

## Color Coding

| Line Color | Meaning |
|-----------|---------|
| Red `RGB(255,0,0)` | Active/selected items |
| Green `RGB(0,255,0)` | Merged items |

## Key Implementation Details

### 1. Async Operation

All handlers that interact with OD Lines are now async:

- `handleSecurityAffectedItemClick`
- `handleSecondaryCardYes`
- `handleSecondaryCardNo`
- `handleClose`
- `handleSubmitToIncidentManagement`

### 2. Initial OD Line Creation

Added to the `useEffect` hook that handles alert card opening:

```typescript
if (alert.category === AlertCategory.SECURITY) {
  const mainCoords = alert.coordinates;
  await addODLines([[mainCoords, mainCoords]]);
  await focusODLines(["od_0"]);
}
```

### 3. Line Direction Logic

```typescript
const startEndPair: number[][] =
  type === "upstream"
    ? [itemCoords, mainCoords] // upstream → main
    : [mainCoords, itemCoords]; // main → downstream
```

### 4. Helper Function: getAllCurrentLineIds

```typescript
const getAllCurrentLineIds = (
  selectedItems: Array<{ type: "upstream" | "downstream"; index: number }>,
  mergedItems: MergedItemData[]
): string[] => {
  const ids: string[] = [];
  
  selectedItems.forEach((item) => {
    ids.push(`od_${item.type}_${item.index}`);
  });
  
  mergedItems.forEach((item) => {
    ids.push(`od_${item.type}_${item.index}`);
  });
  
  return ids;
};
```

## API Methods Used from useDigitalTwinApi

| Method | Purpose | Parameters |
|--------|---------|------------|
| `addODLines` | Create new OD lines | `startEndPairs: number[][][]` |
| `clearODLines` | Remove all OD lines | None |
| `deleteODLines` | Remove specific lines | `ids: string \| string[]` |
| `focusODLines` | Focus camera on lines | `ids: string \| string[]` |
| `setODLineColor` | Change line color | `id: string, newVal: string` |

## Notes

1. **Main→main line (od_0)**: This is the default line ID generated by `addODLines` when creating the self-referencing line. It persists throughout the session unless cleared.

2. **State Management**: All OD line states are temporary and reset when the alert card is closed or the app restarts.

3. **Performance**: OD lines are created/deleted individually for efficiency, avoiding unnecessary full rebuilds.

4. **Focus Behavior**: Camera focuses on all visible lines (both red selected and green merged) to show the complete relationship network.
